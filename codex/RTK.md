# RTK - Rust Token Killer

**Rule**: Prefix verbose shell commands with `rtk` when using Codex.

```bash
rtk git status
rtk git diff
rtk cargo test
rtk npm run build
rtk pytest -q
```

## Meta Commands

```bash
rtk gain
rtk gain --history
rtk proxy <cmd>
```

## Verification

```bash
rtk --version
rtk gain
which rtk
```
